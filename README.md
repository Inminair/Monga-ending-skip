## 기능

### ▶▶| 엔딩 자동 건너뛰기
- 정해 둔 시간(기본 **60초**)이 지나면 영상 끝으로 넘겨서, 재생목록이 곧바로 다음 화를 틀게 해요.
- 마지막 화에서는 그대로 멈춰요.
- 이런 때는 건드리지 않아요.
  - 광고가 나오는 동안
  - **3분이 넘는 영상**(재생목록에 섞인 긴 노래 영상 같은 것)
  - 설정한 재생목록이 아닌 영상

### 🔍 제목으로 찾아가기
- 제목에 들어간 단어로 화를 찾아요. 띄어쓰기는 무시해요.
- 숫자만 넣으면(`15`, `15화`) 그 화가 맨 앞에 나와요.
- 결과를 누르거나 엔터를 누르면 재생목록을 유지한 채 그 화로 바로 이동해요.
- 지금 보고 있는 화에는 `◀ 지금` 표시가 붙어요.
- 받아 온 목록은 12시간 동안 저장해 둬요. 새 화가 올라왔다면 `↻` 버튼으로 다시 받으면 돼요.

### ⚙️ 설정
| 항목 | 설명 |
|---|---|
| 엔딩을 건너뛸까요? | `YES` / `NO`로 켜고 꺼요. |
| 몇 초에 다음 화로 갈까요? | 넘길 시점(초). `◀` `▶`로 1초씩 조절해요. |
| 재생목록 ID 또는 주소 | 건너뛰기를 적용할 재생목록이에요. 주소를 통째로 붙여 넣어도 `list=` 값만 저장해요. 여러 개는 줄바꿈으로 구분하고, 비우면 3분 이하 모든 영상에 적용돼요. |

> 기본값으로 재생목록 하나가 들어 있어요. 보고 싶은 재생목록의 주소로 바꿔서 쓰세요.

## 설치

크롬 웹스토어에는 아직 올라가 있지 않아서, 직접 불러와야 해요.

1. 이 저장소를 내려받아요. (`Code` → `Download ZIP` 후 압축 풀기, 또는 `git clone`)
2. 크롬 주소창에 `chrome://extensions`를 입력해요.
3. 오른쪽 위 **개발자 모드**를 켜요.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, `manifest.json`이 들어 있는 폴더를 골라요.
5. 이미 열려 있던 유튜브 탭은 새로고침해 주세요.

업데이트할 때는 새 파일로 덮어쓴 뒤 `chrome://extensions`에서 이 확장 프로그램의 새로고침(↻)을 누르면 돼요.

## 권한과 개인정보

- 요청하는 권한은 **저장소(`storage`)** 하나뿐이에요. 설정값과 받아 온 재생목록 제목을 브라우저 안에 저장하는 데 써요.
- `www.youtube.com` 페이지에서만 동작해요.
- 어떤 정보도 외부 서버로 보내지 않아요. 재생목록 목록은 유튜브 탭 안에서 유튜브에 직접 요청해서 받아 와요.

## 알아 둘 점

- 찾기 기능은 유튜브 페이지의 내부 데이터 형식을 읽어서 목록을 가져와요. 유튜브가 형식을 바꾸면 "목록을 받아 오지 못했어요"가 나올 수 있어요. 엔딩 건너뛰기에는 영향이 없어요.
- 에피소드마다 본편 길이가 조금씩 다를 수 있어요. 엔딩이 일찍 시작하거나 본편이 잘린다면 설정에서 초를 조절해 주세요.

## 파일 구성

```
├─ manifest.json        확장 프로그램 정보
├─ content.js           엔딩 건너뛰기 (유튜브 페이지에서 동작)
├─ playlist.js          찾기에 쓸 재생목록 전체 목록 받아오기
├─ popup.html / .css / .js   툴바 팝업 (설정 · 찾기)
├─ icons/               툴바 · 확장 프로그램 아이콘 (16 / 32 / 48 / 128px)
├─ fonts/               갈무리 픽셀 폰트 + 라이선스
└─ tools/make-icons.js  아이콘 생성기
```

### 아이콘 다시 만들기

아이콘은 [`tools/make-icons.js`](tools/make-icons.js) 안에 16×16 글자 격자로 그려져 있어요. 격자를 고친 뒤 아래를 실행하면 `icons/`의 PNG가 다시 만들어져요. (Node.js 필요, 추가 패키지 없음)

```bash
node tools/make-icons.js
```
